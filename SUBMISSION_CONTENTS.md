# Final Project Submission Contents

This package follows the assignment-page requirements for the C++ final
project submission.

| Required item | Included file or folder |
| --- | --- |
| Project final report, PDF | `docs/pdf/final-project-report.pdf` |
| Project proposal | `docs/project-proposal-requirements.md` and `docs/pdf/project-proposal-requirements.pdf` |
| Requirements analysis report | `docs/project-proposal-requirements.md` and `docs/pdf/project-proposal-requirements.pdf` |
| Design specification | `docs/design-spec.md` and `docs/pdf/design-spec.pdf` |
| User manual, PDF | `docs/user-manual.md` and `docs/pdf/user-manual.pdf` |
| Program source code with comments | `src/`, `tests/`, `CMakeLists.txt`, `Doxyfile` |
| Test cases with readme/report | `docs/test-cases.md`, `docs/pdf/test-cases.pdf`, `tests/`, `docs/screenshots/` |
| Summary report, PDF | `docs/summary-report.md` and `docs/pdf/summary-report.pdf` |
| AI usage description | `docs/ai-usage.md` and `docs/pdf/ai-usage.pdf` |
| Demo video | `docs/demo.mp4` |
| Tutorial GIF | `docs/tutorial.gif` |
| Runtime assets | `assets/` |
| Runtime model weights | `models/nnue-halfkp-demo.bin`, `models/lc0-cnn-small-112p-4x32-policy4672-wdl3.bin`, `models/lc0-bt4-tiny-96x4x4h.bin` |
| Linux build | `builds/linux-x64/cnnv` |
| Linux test binary | `builds/linux-x64/cnnv_tests` |
| Windows build | `builds/windows-x64/` |

The archive intentionally excludes Git metadata, `.gitignore`, editor files,
CMake cache/build directories, temporary files, and unused large model blobs.
